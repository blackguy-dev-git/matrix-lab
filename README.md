# 🧮 Matrix Lab

A simple, menu-driven matrix calculator built with **Python** and **NumPy**. This project is designed to practise linear algebra concepts and explore how NumPy handles matrix operations.

## ✨ Features

- **Matrix Addition** — Add two matrices.
- **Matrix Subtraction** — Subtract one matrix from another.
- **Matrix Multiplication** — Multiply two matrices using matrix multiplication.
- **Matrix Division** — Perform element-wise division.
- **Null Matrix Check** — Check whether a matrix contains only zeros.
- **Diagonal Matrix Check** — Check whether all off-diagonal elements are zero.

## 🛠️ Technologies Used

- **Python** — Core programming language.
- **NumPy** — Matrix creation and mathematical operations.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/blackguy-dev-git/matrix-lab.git
```

### 2. Open the project directory

```bash
cd matrix-lab
```

### 3. Install NumPy

```bash
python -m pip install numpy
```

### 4. Run the program

```bash
python main.py
```
